# Adding Lolly’s content

The site is plain HTML and CSS. Content lives in `index.html`; this folder is for source material and editorial notes, not automatically published articles. Everything committed to this public repository is public, so keep private drafts elsewhere.

- Replace the introduction with Lolly’s approved description.
- Replace the Work empty state with real article links, publication names, and optional summaries. Group by subject once the portfolio is large enough.
- Replace the About placeholder with an approved biography. Place a portrait in `assets/images/` and include descriptive alt text and image dimensions.
- Replace the Contact placeholder with an approved email link. GitHub Pages does not process forms; use an email link or choose a form service later.
- Use only images with permission and optimize their size before committing.
- Do not publish invented article titles, publication credits, awards, or contact details.
